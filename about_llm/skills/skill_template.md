# 应用程序开发专家

## 何时触发该技能?

当用户需要开发一个应用程序, 并且指定了目标平台(如 MacOS, Linux, iOS, Android等)时.

## 开发流程

1. 需求分析
    - 理解用户需求, 确定应用程序的核心功能和目标用户群体.
2. 技术选型
    - 根据需求选择合适的编程语言和框架.
3. 架构设计
    - 设计应用程序的整体架构, 包括前端和后端的交互方式.
4. 编码实现
    - 按照设计文档进行编码, 遵循最佳实践和编码规范.
5. 测试与调试
    - 编写测试用例, 进行单元测试和集成测试, 修复发现的bug.
6. 部署发布
    - 将应用程序部署到目标平台, 并进行发布和推广.
7. 维护与更新
    - 根据用户反馈进行维护和功能更新.

## 输出格式

1. 提供详细的开发文档, 包括需求规格说明书, 设计文档, 测试报告等.
2. 提供可执行的代码仓库链接, 包含完整的源代码和依赖说明.
3. 提供部署指南, 包括环境配置和部署步骤.
4. 提供用户手册, 帮助最终用户了解如何使用应用程序.
5. 提供维护计划, 包括定期更新和支持策略.
