# Antigravity 全局技能集 (Global Skills)

这是一系列生产级技能集合,旨在扩展 Antigravity AI 代理的能力边界.这些技能封装了各个领域的技术专家经验、最佳实践和专业工作流.

## 🚀 核心与策略 (Core & Strategy)
- **using-superpowers**: 技能发现与调度的枢纽,确保在对话开始时选择最合适的工具.
- **brainstorming**: 深入的需求分析与创意探索,在动手开发前明确目标与逻辑.
- **writing-plans**: 高精度的技术规格书与实施计划编写,确保复杂任务有序执行.
- **executing-plans**: 系统化执行已批准的多步实施计划,保证交付的一致性.
- **subagent-driven-development**: 通过独立子代理进行并行任务处理,提升开发效率.

## 💻 工程与语言 (Engineering & Languages)
- **typescript-pro / javascript-pro**: 使用现代 ES2023+ 特性进行全栈开发,强调类型安全.
- **python-pro**: 专业的 Python 3.11+ 开发,专注类型提示、异步编程与架构模式.
- **rust-engineer**: 内存安全的系统级编程,处理高性能后端逻辑与底层组件.
- **vue-expert**: 使用 Vue 3、Nuxt 3 和 Pinia 进行高级前端开发.
- **devops-engineer**: 基础设施即代码 (IaC)、CI/CD 流水线与容器编排.

## 🎨 设计与创意 (Design & Creative)
- **frontend-design**: 高保真、高审美的生产级 UI/UX 设计与实现.
- **canvas-design**: 专业的视觉艺术、海报设计与排版系统.
- **theme-factory**: 为代理生成的所有文档和界面提供多样化的视觉风格与主题.
- **imagen**: 利用 Imagen 模型生成 UI 原型、图标、插图等视觉素材.
- **brand-guidelines**: 严格遵循企业品牌视觉识别标准 (VI) 进行内容产出.

## 🔍 专业领域 (Specialized Domains)
- **deep-research**: 调用深度研究代理执行市场调研、竞争分析并生成详细报告.
- **architecture-designer**: 高级系统架构设计、模式评审及决策记录 (ADR).
- **code-reviewer / code-documenter**: 通过代码审计确保质量,并通过详尽的文档提升可维护性.
- **game-developer**: 针对游戏引擎环境的逻辑实现、物理系统及性能优化.
- **fine-tuning-expert**: 定制化的 LLM 模型微调、数据集工程与性能调优.
- **prompt-engineer**: 高级提示词优化、推理链构建与逻辑工程.

## 📋 通用工具 (Utilities)
- **hello-skill**: 标准化的会话启动声明,确认技能加载状态.
- **skill-creator**: 用于构建、扩展和维护技能生态系统的框架.
