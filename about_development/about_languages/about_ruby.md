#### 📒 What's Rails

- [Rails](https://github.com/rails/rails)

```bash
# Rails 是 Ruby 社区最著名、对整个 Web 生态影响最大的Web 应用程序框架。它推广了 “约定优于配置（Convention over Configuration）” 和 “快速开发” 的理念，深刻影响了后来的全栈框架设计模式.

# installation:
    gem install rails
    rails new myapp
    cd myapp
    bin/rails server
```
