- 开源, 用于构建和部署 AI 驱动的代理和工作流

- 基于 LangChain 架构
- 适合快速搭建、调试和部署本地或远程的大语言模型服务
# Langflow 是一个功能强大的平台，用于构建和部署 AI 驱动的代理和工作流。它为开发者提供可视化创作体验以及内置的 API 和 MCP 服务器，可以将每个工作流转化为可集成到基于任何框架或技术栈构建的应用程序中的工具。Langflow 功能齐全，支持所有主流的 LLM、向量数据库以及不断增长的 AI 工具库
