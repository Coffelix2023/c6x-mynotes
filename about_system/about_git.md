# git commander

- 创建新仓库(repository)

```
echo "# c6x-mynotes" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin git@github.com:Coffelix2023/c6x-mynotes.git
git push -u origin main
```

- 推送仓库(push repository)

```
git remote add origin git@github.com:<git>
git branch -M main
git push -u origin main

```
