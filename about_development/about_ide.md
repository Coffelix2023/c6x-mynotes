- 📒 vscode

# installation
    brew install visual-studio-code

- 📒 vscode-insiders

```bash
# vscode的开发版本
# installation
    brew install viusal-studio-code@insiders
```

- 📒 codium

```bash
# MIT开源版本, 无扩展商店
# installation
    brew install vscodium
```

- 📒 [zed](https://zed.dev/)

```bash
# Build in Rust, 极简美学代码编辑器，专为速度和人机协作而设计
# installation
    brew install zed
```

- 📒 [neovim](https://neovim.io/)

```bash
# 终端编辑器, Vim的增强版本, 支持插件和扩展
# installation
    brew install neovim
    nvim [file]
```

amp 是终端代码编辑器, Rust编写
