## 其他游戏引擎笔记

### 📒 Phaser.js

```bash
# 什么是Phaser.js?
  - 专为 web 2D游戏开发的框架,采用js/ts

# 关于物理引擎
  - 包含两个物理引擎: Arcade 和 Matter
  - Arcade : 轻量, 快速处理简单刚体
  - Matter : 复杂交互的综合性物理引擎

# 关于渲染
  - phaser 自定义渲染器, 支持 WebGL 和 Canvas

# 什么是phaser launcher (启动器)
  - 免费桌面应用, 特点是:
    - 代码编辑器
    - 媒体浏览器
    - 项目管理
    - Game Runner : 编码时 play/ debug/ hot-reload \* 教程和示例
# 初始化
    pnpm create @phaserjs/game@latest
```
